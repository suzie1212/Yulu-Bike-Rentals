# Yulu-Bike-Rentals
It was observed that the number of bike rentals changes across different seasons and weather conditions. To understand the reasons behind these fluctuations, an analysis was conducted on Yulu's bike rental data.
The goal is to identify the factors that have the greatest impact on demand and understand how customer usage varies with weather, seasonality, holidays, and working days. The insights from this analysis can help explain rental patterns and support data-driven business decisions.
